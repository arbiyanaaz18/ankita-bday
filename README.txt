ANKITA'S BIRTHDAY WEBSITE
Folders: index.html, style.css, script.js, images/ (your photos), videos/ (your clips)

RUN LOCALLY: double-click index.html (or run: python3 -m http.server, open localhost:8000)

PUBLISH (free, ~2 minutes): 
1. Go to app.netlify.com/drop  (or Cloudflare Pages / GitHub Pages / Vercel)
2. Drag the whole "ankita" FOLDER (or unzip the zip first) onto the page.
3. Copy the link it gives you and send it to Ankita. Keep the folder structure as is.

MUSIC: built-in music-box tune plays after "Tap to open" (🎵 button = mute). The Happy Birthday tune plays when she blows the candles.
To use her favourite song instead: put your own file in the music folder named exactly  song.mp3  (it replaces the lullaby automatically).
